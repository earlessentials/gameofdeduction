# Plum and pearl refinement

The homepage now combines the requested plum, aubergine and orchid colors with pearl mint, blue, lavender and seafoam. Editorial serif typography, varied image proportions, open layouts and subtle paper treatments replace repetitive boxed sections. Rounded controls and the original animated investigation eye remain.

## Evidence workflow

Current-phase evidence records appear together on desktop and stack on phones. Opening the records uses one server action, restricted to the current unlocked phase. The Deduction view also includes the records on mobile. Pins, highlights, bilingual content and notebook persistence remain available. Future evidence and answer keys stay server protected.

## Reliability and performance

Browser JavaScript and CSS use versioned, cacheable assets. Initial homepage HTML decreased from 185,077 to 11,818 bytes in the local comparison; this is an HTML transfer measurement, not a complete page-load or Core Web Vitals claim. Routine actions no longer fetch a redundant full profile. Rapid actions queue, note saves serialize, identity changes isolate state, and background presence uses a lightweight endpoint. Offscreen/hidden animation pauses; visible motion remains. Owner statistics aggregate through two queries.

## Verification

Passed game journeys across all 24 bilingual investigations, serialized network progression, account isolation, concurrent active-case enforcement, persistence, UI rendering, public metadata, asset caching and performance regression checks. Added coverage for opening both current-phase sources without exposing later stages. Browser checked paired sources, mobile stacking without overflow, tab switching and notes after refresh. No storage schema migration or change to existing progression rules.

Cross-browser hardware performance and live Core Web Vitals remain unmeasured.
